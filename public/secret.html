Geheimlink

Passwörter, Zugangsdaten oder private Notizen sicher weitergeben: Der Link funktioniert genau einmal, danach ist der Inhalt für immer gelöscht.

✅ Dein Geheimlink

Schick ihn über einen beliebigen Messenger. Sobald ihn jemand öffnet, ist er verbraucht.

So funktioniert's

  1. Dein Text wird in deinem Browser verschlüsselt (AES-256-GCM).
  2. Der Schlüssel steht nur im Link hinter dem # – dieser Teil wird nie an den Server geschickt.
  3. Der Server speichert nur unlesbaren Datensalat und löscht ihn beim ersten Öffnen oder nach Ablauf.
  4. Link-Vorschauen in WhatsApp & Co. verbrauchen den Link nicht – erst der Klick auf „Anzeigen“.
